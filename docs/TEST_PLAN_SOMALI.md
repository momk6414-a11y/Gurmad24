# Qorshaha tijaabada GURMAD 24 (Demo)

## Tijaabooyin otomaatig ah (`npm test`)
Auth & session, doorar (matrix), onboarding isbitaal, abuurista/daabacaadda kaarka, dalabyo, komishan, rukumo, ballamo (+khidmad/komishan shaybaar), lacag-celin (ansixin/diidmo), warbixinno & CSV, cabashooyin, kiisaska jilitaanka, amniga API (CSRF, 415, rate limit, headers, mass-assignment), asturnaan (export/delete), database joogto ah, migrations, backup, retention.

## Tijaabo gacanta ah (taleefan)
1. Fur app-ka → arag **QAAB TIJAABO AMAAN AH**. Beddel luqadda SO/EN.
2. Samee akoon bukaan → dooro kaar → **Dalbo** → arag rasiid (DEMO).
3. Codso ballan isbitaal → isbitaalka ku gal → xaqiiji → bukaanka arag xaaladda.
4. Codso lacag-celin → maamule ku gal → ansixi → hubi dakhliga.
5. Samee codsi gurmad (jilitaan) → hawlgale ku gal → qoondee ambalaas → bixiyaha ku gal → hormari xaaladda.
6. Admin → Revenue → Export CSV.
7. Rakib PWA (HTTPS) → hubi in ay u furmaan shaashad buuxda.

## Shuruudaha guusha
- Shaashadaha way ka muuqdaan telefoon yar; ma jiro wicitaan/fariin dibadda loo diro.
- Dalab/kiis kasta wuxuu muujiyaa **DEMO/JILITAAN**; isticmaaluhu wuu garanayaa inaanay ahayn adeeg dhab ah.
